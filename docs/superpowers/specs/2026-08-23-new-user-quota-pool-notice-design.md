# 新用户默认额度池提示设计

## 目标

当普通成员仍位于新用户默认额度池时，在额度池概览中明确说明该额度仅用于一次性体验，并引导用户联系部门额度池负责人迁移到对应额度池。

提示文案为：

> 请及时联系部门额度池负责人添加到对应额度池。当前额度池为体验额度，仅赠送一次，用完即止。

## 展示规则

- 仅当当前用户以普通成员视图查看自己的额度池，并且额度池的 `pool_type` 为 `new_user` 时展示。
- 系统管理员、额度池超级管理员及额度池管理员进入管理详情时不展示。
- `pool_type=default` 的存量默认池不展示；不得通过额度池名称或 `is_default` 推断新用户池。
- 提示常驻在额度池详情的“概览”页顶部，不使用一次性 Toast，也不允许用户关闭。

## 前端实现

- 在 `QuotaPoolDetail` 的概览内容中增加语义化 `Alert`。
- 提示采用警示图标和简短标题“体验额度说明”，正文使用确认后的提示文案。
- 图标标记为装饰性，提示组件保留 `role=alert`，确保辅助技术可以读取。
- 布局使用现有 shadcn 风格的 `Alert`，适配移动端和深色主题，不新增依赖。
- 所有用户可见文案通过 `t(...)` 渲染，并同步补齐 `en`、`zh`、`zh-TW`、`fr`、`ru`、`ja`、`vi` 七种语言。

## 数据与接口

- 复用现有 `QuotaPool.pool_type` 字段和 `selfMode`、capability 信息。
- 不新增或修改 HTTP API、数据库字段、迁移、权限规则及额度池资金逻辑。

## 测试与验收

- 普通成员查看 `pool_type=new_user` 的自己的额度池时可以看到提示。
- 普通成员查看普通额度池时看不到提示。
- 管理员以管理视图查看新用户额度池时看不到提示。
- 运行受影响组件测试、七语言 i18n 同步检查、TypeScript 类型检查、涉及文件 lint、格式检查和生产构建。

## 非目标

- 不在登录、Dashboard 或其他页面重复弹出提示。
- 不增加联系负责人按钮、自动迁移或通知功能。
- 不改变新用户额度的发放次数、额度值或耗尽行为。
